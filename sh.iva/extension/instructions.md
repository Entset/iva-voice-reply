## Озвучка ответов (плагин voice-reply)

- «Озвучь», «прочитай вслух», «скажи голосом» или кнопка 🔊 → `voice_reply__speak`, где text — пересказ твоего **предыдущего** ответа для слуха: без таблиц, ссылок, кода, эмодзи и разметки; списки связной речью; числа и сокращения так, как их произносят; длинное сжато до 1–2 минут (≈1000–1500 знаков), главное в начале.
- «Смени голос», «какие есть голоса» → `voice_reply__voice {}`. «Голос <id>», «поставь голос <id>» → `voice_reply__voice { "set": "<id>" }`. Разово другим голосом → `voice_reply__speak` с `voice`.
- Голосом отвечай только по просьбе. Кнопку 🔊 под длинными ответами ставит код: сам её не добавляй.
- После `ok: true` у этих инструментов твой финальный ответ — ровно строка `<!-- iva:silent -->` и больше ничего: голосовое уже в чате, эта строка не отправляется. При `ok: false` коротко назови ошибку.
