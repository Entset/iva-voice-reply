# voice-reply — Ива читает ответы вслух

Плагин для [Ивы](https://github.com/smixs/iva-agent): любой письменный ответ она может прислать в Telegram **голосовым сообщением**. Удобно, когда читать неудобно, например за рулём.

- Под каждым длинным ответом (больше 600 знаков), прямо в самом сообщении, появляется кнопка **🔊 Озвучить**. Можно и просто написать или сказать «озвучь» или «прочитай вслух».
- Она не зачитывает текст дословно, а пересказывает его для слуха: без таблиц, ссылок и разметки.
- После голосового ничего не дописывает: ни текста, ни эмодзи.
- Голоса меняются прямо в чате.

## Голосовой и текстовый режим (0.7.0)

По умолчанию Ива отвечает текстом, голосовое — по кнопке 🔊 или по разовой просьбе.

- Скажешь «**отвечай мне голосом**» (или «говори со мной голосом», «озвучивай весь текст», «перейди на голосовые») — каждый её следующий ответ приходит голосовым. Слова ловит хук `mode-watcher`, выбор запоминается и переживает перезапуск.
- Скажешь «**пиши мне текстом**» (или «выключи голосовой режим», «хватит голосовых») — вернётся текстовый режим.
- Разовые просьбы режим не меняют: «Озвучь», кнопка 🔊, «Сделай ответ текстом», «найди голос eve», смена голоса.

Режим хранится в `data/plugin-data/voice-reply/mode`, действует во всех чатах до смены.

## Два режима (выбор при установке)

| | Бесплатный (local) | Платный (cloud) |
|---|---|---|
| Движок | Silero v5, работает на вашем сервере | OpenRouter (Grok / Gemini) |
| Ключ | не нужен | OpenRouter `sk-or-…` |
| Расход | 0 ₽ | ~$0.01–0.015 за минуту речи |
| Голоса из коробки | `zinaida` (жен., спокойный), `eduard` (муж.) | `eve`, `erinome`, `charon`, `iapetus` |
| Приватность | текст не покидает сервер | текст уходит в OpenRouter и провайдеру голоса |

Первый выбор делает владелец: «выбери платный режим озвучки» / «выбери бесплатный режим озвучки» (параметр `engine` у `voice_reply__voice`). Движок записывается в `data/plugin-data/voice-reply/engine` и переживает обновления.

### Голоса

| Голос | Режим | Характер |
|---|---|---|
| `zinaida` (по умолчанию в local) | Silero, локально | женский, спокойный |
| `eduard` | Silero, локально | мужской |
| `eve` (по умолчанию в cloud) | Grok (xAI) | женский, бодрый, британский акцент |
| `erinome` | Gemini 3.8 Flash TTS | женский, чёткий |
| `charon` | Gemini 3.8 Flash TTS | мужской, информативный |
| `iapetus` | Gemini 3.8 Flash TTS | мужской, чёткий |

## Что нужно

- Ива с поддержкой плагинов (`iva plugin`)
- `ffmpeg` на сервере (`sudo apt install ffmpeg`) — нужен для обоих режимов
- Для платного режима: ключ [OpenRouter](https://openrouter.ai) с положительным балансом
- Для бесплатного режима: локальный движок Silero v5 (см. ниже). **Требования к серверу:** ~1 ГБ на диске (окружение Python с torch ≈900 МБ + модель 88 МБ), ~1 ГБ оперативной памяти при синтезе, достаточно 1–2 vCPU: секунда речи собирается примерно за 0.15–0.3 с на одном ядре.

## Установка бесплатного движка (Silero v5)

Изолированное окружение в `~/tts`, ничего в системе Ивы не трогает:

```bash
cd ~ && mkdir -p tts && cd tts
~/.local/bin/uv venv venv --python 3.12        # или python3 -m venv venv
venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu
venv/bin/pip install numpy omegaconf num2words silero-stress
curl -L https://models.silero.ai/models/tts/ru/v5_cis_base.pt -o v5_cis_base.pt
```

Скрипт движка лежит в репозитории: `bin/tts_silero.py`. Скопируйте его в постоянное место плагина (оно переживает обновления плагина и Ивы):

```bash
mkdir -p ~/iva/data/plugin-data/voice-reply/bin
cp bin/tts_silero.py ~/iva/data/plugin-data/voice-reply/bin/
chmod +x ~/iva/data/plugin-data/voice-reply/bin/tts_silero.py
```

Пути по умолчанию под наш сервер (`/home/lnsrtw/tts/…`); для другого сервера переопределите их в `.env` Ивы:

```bash
echo 'SILERO_PYTHON=/home/ваш_путь/tts/venv/bin/python' >> ~/iva/.env
echo 'SILERO_MODEL=/home/ваш_путь/tts/v5_cis_base.pt' >> ~/iva/.env
```

Готовность движка проверяется на каждый вызов: установили после запуска Ивы — режим заработает без перезапуска (после `SILERO_PYTHON` в `.env` нужен `iva restart` или `/restart`).

В модели 29 русских голосов (`ru_zinaida`, `ru_eduard`, `ru_karina`, `ru_oksana`, `ru_vika`, `ru_aigul`, `ru_albina`, `ru_alexandr`, `ru_bogdan`, `ru_ekaterina`, `ru_roman`, `ru_dmitriy` и др.). Добавить голос — одна строка в `VOICE_CATALOG` (`sh.iva/extension/lib/catalog.ts`) с `speaker: "ru_..."`.

## Установка

Есть два способа: попросить Иву или поставить из терминала. Результат одинаковый.

### Способ 1. Через Иву, прямо из Telegram

1. Напишите Иве:

   > Установи плагин https://github.com/Entset/iva-voice-reply

   Ива скачает плагин и пришлёт сообщение с описанием и кнопкой **«Установить»**. Плагин содержит код, поэтому поставить его без вашего нажатия Ива не может — это защита самой Ивы.
2. Нажмите **«Установить»**. Ива пересоберётся и перезапустится (1–2 минуты). Если сборка не удастся, установка откатится, а текущая версия продолжит работать.
3. Выберите режим: **«выбери платный режим озвучки»** или **«выбери бесплатный режим озвучки»**.
   - Платный: пришлите Иве ключ OpenRouter (`sk-or-…`, создаётся на [openrouter.ai/keys](https://openrouter.ai/keys)) — Ива проверит ключ и сохранит его. Озвучка заработает сразу, без перезапуска.
   - Бесплатный: выполните блок «Установка бесплатного движка» выше, затем скажите Иве «проверь озвучку».

> **О ключе в чате.** Сообщение с ключом проходит через модель Ивы и остаётся в истории чата. Поэтому:
> - после сохранения удалите сообщение с ключом из Telegram;
> - поставьте ключу лимит расходов на [openrouter.ai/keys](https://openrouter.ai/keys), например $10;
> - если сомневаетесь — используйте способ 2: там ключ не проходит через чат.

### Способ 2. Из терминала на сервере

1. Для платного режима добавьте ключ в `.env` Ивы (обычно это `~/iva/.env`):

   ```bash
   echo 'OPENROUTER_API_KEY=sk-or-...' >> ~/iva/.env
   ```

2. Поставьте плагин:

   ```bash
   iva plugin add Entset/iva-voice-reply
   ```

3. Для бесплатного режима дополнительно выполните блок «Установка бесплатного движка» и скажите Иве «выбери бесплатный режим озвучки».

Ключ из `.env` важнее сохранённого через чат.

### Инструкция для Ивы

*Этот блок адресован самой Иве: владелец прислал ссылку на этот репозиторий и попросил установить плагин.*

1. Проверь ffmpeg: `command -v ffmpeg`. Если его нет, скажи владельцу, что нужно выполнить `sudo apt install ffmpeg` (sudo у тебя нет), и продолжай установку — без ffmpeg не будет работать только сама озвучка.
2. Скачай плагин в папку черновиков:

   ```bash
   git clone --depth 1 https://github.com/Entset/iva-voice-reply data/custom/plugin-drafts/voice-reply
   ```

   Если папка уже есть, обнови её: `git -C data/custom/plugin-drafts/voice-reply pull --ff-only`.

3. Спроси владельца, какой режим ему нужен: платный (OpenRouter, качество выше) или бесплатный (Silero на его сервере). Опиши двумя строками разницу из таблицы выше.
4. Предложи установку: `iva plugin propose data/custom/plugin-drafts/voice-reply`. Заверши ход фразой «отправила предложение, жду тапа» и не проверяй результат — он придёт сообщением.
   - Если propose ответил, что плагин уже установлен: обновление делает владелец в своём терминале — `iva plugin update voice-reply`. Скажи ему это.
5. После установки выбери режим за владельца:
   - платный → попроси ключ OpenRouter и сохрани его `voice_reply__set_key`; ключ не повторяй и не записывай в память;
   - бесплатный → проверь готовность движка (`localReady`: есть `~/tts/venv/bin/python`, модель `~/tts/v5_cis_base.pt` и скрипт в `data/plugin-data/voice-reply/bin/`). Если движка нет — предложи блок «Установка бесплатного движка» из README или платный режим.
6. Прислуай образцы голосов выбранного режима (`voice_reply__voice` без аргументов) и сохрани выбор владельца (`set`). У бесплатного режима образцов два: `zinaida.local` и `eduard.local`.

## Как пользоваться

| Что написать или сказать | Что произойдёт |
|---|---|
| «озвучь», «прочитай вслух», кнопка 🔊 | голосовое с предыдущим ответом |
| «смени голос», «какие есть голоса» | образцы голосов текущего режима с кнопками «Выбрать …» |
| «поставь голос zinaida» / «поставь голос eduard» | голос сохранится насовсем |
| «озвучь голосом eduard» | один ответ другим голосом, основной не меняется |
| «выбери бесплатный режим озвучки» («платный») | сменить движок (one-time установка режима) |

Выбранный голос и режим хранятся в `data/plugin-data/voice-reply/` (`voice`, `engine`) и переживают и обновление плагина, и `iva update`.

## Стоимость

- **Бесплатный режим (Silero):** 0 ₽, всё считается на вашем сервере. Скорость: секунда речи синтезируется примерно за 0.15–0.2 с на 2 vCPU.
- **Платный режим (OpenRouter), за символы озвученного текста:**
  - Gemini (`erinome`, `charon`, `iapetus`): около $0.01 за минуту речи
  - Grok (`eve`): около $0.015 за минуту

$10 хватает на несколько сотен озвученных ответов. Цены примерные, актуальные — на [openrouter.ai/models](https://openrouter.ai/models).

У нового аккаунта OpenRouter на Gemini действует ограничение по числу запросов в минуту. Если много раз подряд просить «смени голос», образцы могут на минуту перестать приходить.

## Безопасность и приватность

- **Что уходит наружу:**
  - бесплатный режим — ничего: вся озвучка на вашем сервере, наружу уходит только само голосовое в Telegram (Bot API);
  - платный режим — текст для озвучки уходит в OpenRouter, а оттуда к провайдеру голоса (xAI или Google).
- **Ключи** берутся из `.env` (`OPENROUTER_API_KEY`, `TELEGRAM_BOT_TOKEN`). Ключ, присланный через чат, проверяется в OpenRouter и хранится в `data/plugin-data/voice-reply/openrouter.key` с правами 600 (читает только владелец). Плагин никогда не возвращает ключ модели, а в текстах ошибок ключи маскируются.
- **Дочерние процессы без shell:** ffmpeg и движок Silero запускаются с фиксированными аргументами, текст в командную строку не попадает.
- **Расход ограничен:** за один вызов озвучивается не больше 8000 знаков (около 10 минут речи), у запросов таймаут 2 минуты.
- **В памяти плагина** только название голоса, режим и (если прислал через чат) ключ OpenRouter.
- Кнопка 🔊 ставится только на ответ в текущем разговоре и никогда в фоновых ходах (ночная память, напоминания).

В плагине есть код (eve Extension в `sh.iva/`), поэтому Ива ставит его только из терминала владельца или после его нажатия «Установить». Прочитайте код перед установкой: его немного, смотрите `sh.iva/extension/`.

## Как устроено

```
Платный:   текст → OpenRouter /api/v1/audio/speech (mp3/pcm) → ffmpeg → ogg/opus → sendVoice
Бесплатный: текст → tts_silero.py (Silero v5 + ударения, ffmpeg внутри) → ogg/opus → sendVoice
```

- `voice_reply__speak` — озвучить текст
- `voice_reply__voice` — образцы голосов и выбор по умолчанию; `engine` — выбор режима (cloud/local)
- `voice_reply__set_key` — проверить и сохранить ключ OpenRouter, присланный через чат
- `lib/catalog.ts` — каталог голосов обоих движков: добавить голос = одна строка
- `hooks/speak-button.ts` — прикрепляет кнопку 🔊 к только что отправленному длинному ответу (`editMessageReplyMarkup`). Ядро Ивы не сообщает номер сообщения с ответом, поэтому хук находит его сам: в чате номера идут подряд, и ответ — последнее сообщение бота после вашего. Кнопку ставит код, а не модель, поэтому она не теряется. Если у ответа уже есть свои кнопки, хук его не трогает.
- `instructions.md` — правила для модели в каждом ходе: когда озвучивать, как пересказывать для слуха, и что после голосового отвечать служебной строкой `<!-- iva:silent -->`. Ива её вырезает, так что в чат ничего лишнего не уходит, а ход не считается упавшим.

После правки кода выполните `iva plugin update voice-reply` (в терминале владельца).

Проверка: `node --test test/*.test.ts`

## Удаление

```bash
iva plugin remove voice-reply
```
