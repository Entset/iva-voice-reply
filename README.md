# voice-reply — Ива читает ответы вслух

Плагин для [Ивы](https://github.com/smixs/iva-agent): любой письменный ответ она может прислать в Telegram **голосовым сообщением**. Удобно, когда читать неудобно, например за рулём.

- Под каждым длинным ответом (больше 600 знаков) появляется кнопка **🔊 Озвучить**. Можно и просто написать или сказать «озвучь» или «прочитай вслух».
- Она не зачитывает текст дословно, а пересказывает его для слуха: без таблиц, ссылок и разметки.
- После голосового ничего не дописывает: ни текста, ни эмодзи.
- На выбор 4 голоса, менять их можно прямо в чате.

| Голос | Модель | Характер |
|---|---|---|
| `erinome` (по умолчанию) | Gemini 3.8 Flash TTS | женский, чёткий |
| `eve` | Grok (xAI) | женский, бодрый, британский акцент |
| `charon` | Gemini 3.8 Flash TTS | мужской, информативный |
| `iapetus` | Gemini 3.8 Flash TTS | мужской, чёткий |

Все голоса хорошо читают по-русски. Это проверено распознаванием речи на тестовой фразе.

## Что нужно

- Ива с поддержкой плагинов (`iva plugin`)
- Ключ [OpenRouter](https://openrouter.ai) с положительным балансом. Он нужен только для озвучки, думает Ива по-прежнему на своей модели.
- `ffmpeg` на сервере (`sudo apt install ffmpeg`): он переводит звук в формат голосовых Telegram (ogg/opus)

## Установка

1. Добавьте ключ в `.env` Ивы (обычно это `~/iva/current/.env`):

   ```bash
   echo 'OPENROUTER_API_KEY=sk-or-...' >> ~/iva/current/.env
   ```

2. Поставьте плагин **из своего терминала** на сервере:

   ```bash
   iva plugin add Entset/iva-voice-reply
   ```

   Ива сама пересоберётся с плагином и перезапустится. Если сборка не удастся, установка откатится, а текущая версия продолжит работать.

Больше ничего настраивать не нужно: правила для модели и кнопка 🔊 приходят вместе с плагином.

## Как пользоваться

| Что написать или сказать | Что произойдёт |
|---|---|
| «озвучь», «прочитай вслух», кнопка 🔊 | голосовое с предыдущим ответом |
| «смени голос», «какие есть голоса» | образцы всех 4 голосов с кнопками «Выбрать …» |
| «поставь голос charon» | голос сохранится насовсем |
| «озвучь голосом eve» | один ответ другим голосом, основной не меняется |

Выбранный голос хранится в `data/plugin-data/voice-reply/voice` и переживает и обновление плагина, и `iva update`. Голос по умолчанию можно задать и через `VOICE_REPLY_VOICE=eve` в `.env`, но сохранённый выбор важнее.

## Стоимость

Платите OpenRouter за символы озвученного текста:

- Gemini (`erinome`, `charon`, `iapetus`): около $0.01 за минуту речи
- Grok (`eve`): около $0.015 за минуту

$10 хватает на несколько сотен озвученных ответов. Цены примерные, актуальные — на [openrouter.ai/models](https://openrouter.ai/models).

У нового аккаунта OpenRouter на Gemini действует ограничение по числу запросов в минуту. Если много раз подряд просить «смени голос», образцы могут на минуту перестать приходить.

## Безопасность и приватность

- **Что уходит наружу:** только текст для озвучки. Он уходит в OpenRouter, а оттуда к провайдеру голоса (xAI или Google). Само голосовое уходит в тот чат Telegram, откуда пришла просьба (через Bot API с токеном вашего бота).
- **Ключи** берутся из `.env` (`OPENROUTER_API_KEY`, `TELEGRAM_BOT_TOKEN`). Плагин их никуда не записывает, а в текстах ошибок они маскируются.
- **ffmpeg** запускается без shell и с фиксированными аргументами: текст в командную строку не попадает.
- **Расход ограничен:** за один вызов озвучивается не больше 8000 знаков (около 10 минут речи), у запросов таймаут 2 минуты.
- Плагин хранит только название выбранного голоса.
- Кнопка 🔊 уходит только в чат текущего разговора и никогда в фоновых ходах (ночная память, напоминания).

В плагине есть код (eve Extension в `sh.iva/`), поэтому Ива ставит его только из терминала владельца или после его нажатия «Установить». Прочитайте код перед установкой: его немного, смотрите `sh.iva/extension/`.

## Как устроено

```
текст ответа → OpenRouter /api/v1/audio/speech (mp3 или pcm)
             → ffmpeg → ogg/opus → Telegram sendVoice → чат, где идёт разговор
```

- `voice_reply__speak` — озвучить текст
- `voice_reply__voice` — образцы голосов и выбор голоса по умолчанию
- `hooks/speak-button.ts` — после длинного ответа в Telegram отправляет тихое сообщение с кнопкой 🔊. Кнопку ставит код, а не модель, поэтому она не теряется.
- `instructions.md` — правила для модели в каждом ходе: когда озвучивать, как пересказывать для слуха, и что после голосового отвечать служебной строкой `<!-- iva:silent -->`. Ива её вырезает, так что в чат ничего лишнего не уходит, а ход не считается упавшим.

Свой голос добавляется одной строкой в `VOICE_LIST` (`sh.iva/extension/lib/voice.ts`): подойдёт любая TTS-модель OpenRouter. После правки выполните `iva plugin update voice-reply`.

Проверка: `node --test test/*.test.ts`

## Удаление

```bash
iva plugin remove voice-reply
```
